## Structure
Each Task folder contains a standalone `Main.java` and task README. The code is intended for Java 17 or later.

## Run a task
Open the task folder in VS Code terminal and run:
```bash
javac Main.java
java Main
```
For Swing tasks, run on a desktop with a graphical display. For CO5 Task 7 and Task 8, configure MySQL and add the MySQL Connector/J driver to the classpath; set `DB_URL`, `DB_USER`, and `DB_PASSWORD`.
